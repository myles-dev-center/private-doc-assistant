How scoring works

Scoring is deterministic — no LLM judges another LLM. Lookup answers must contain the expected value (dates and amounts are normalized across formats). Aggregate answers must list exactly the expected contracts: one missing or one extra contract makes the answer wrong. Unanswerable questions must be declined; asserting anything counts as a hallucination. A wrong answer is counted as a hallucination; saying “not found” for an answerable question is a miss, not a hallucination.
